# Version 3.0.0 — The Polygon Frequency

This is a SOURCE-CODE RELEASE. It has not been deployed to BVTech servers or integrated with portal.bvtech.org. The `webp` title illustration is concept art, not a game screenshot.

**New:** self-contained WebGL2 low-poly 3D overworld (camera orbit, zoom, fog, colored shading), accessibility 2D mode, display/audio settings and fullscreen, original title artwork, server-run 90-second solo survival, 7-minute multi-person relay, multi-person checkpoint sprint, duo rhythm jam, cosmetic pets, refreshed props and more collectible gear.

**Kept from v2:** six regions, 3 party rifts, NPCs, quests, combat, Hushling boss, shop, housing, saving, game accounts, moderation, quick-chat-only default, reports, PvP consent and normal loot.

**Validated:** Node static syntax checks; four integration test groups for accounts, server movement and reward protection, co-op, houses, moderation, solo survival and two-account jam. All pass as of 2026-10-25.

**Not yet validated:** 3D graphics rendered on actual WebGL2 GPU; load/performance targets on Linode; child privacy, accessibility, security penetration testing, moderation staffing, end-to-end mobile device test, SSO integration and legal documents. Browser headless graphics validation was blocked by the environment (WebGL2 context denied). The legacy 2D view remains as a supported fallback; review the 3D renderer on your target browser/device before public distribution.

**No copied content:** games and characters mentioned as inspiration have not been used as asset sources. See LICENSE-ASSETS.md.
