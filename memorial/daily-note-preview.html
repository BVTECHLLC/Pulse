How it lives on autumnpolasek.com

This is a self-updating widget — no server, no scheduled job, nothing that can quietly break. The page itself chooses a different note every calendar day and never repeats two days running.

  1. Open memorial/daily-note-to-autumn.html from the Pulse repo.
  2. Paste the <div> + <style> + <script> block into the memorial page where you'd like the note to sit.
  3. Re-upload the page to Cloudflare. That's the last time it needs a hand — it rotates by date from then on.

Add or reword notes anytime by editing the NOTES list; the rotation adjusts to the new count automatically.
